# Sentence Translator App

A simple and interactive **Sentence Translator Web Application** built using **HTML, CSS, and JavaScript** that allows users to translate text between different languages using a translation API.

## Overview

The Sentence Translator App provides a user-friendly interface where users can enter text, select the source and target languages, and instantly receive translated output.

The application integrates with a translation API to process language conversion, making it capable of handling real-time translations directly from the browser.

## Features

- Translate sentences between multiple languages.
- Simple and responsive user interface.
- Real-time API-based translation.
- Supports source and target language selection.
- Handles user input and displays translated results dynamically.
- Built with lightweight frontend technologies.

## How It Works

1. User enters a sentence in the input text area.
2. User selects the source language and desired target language.
3. The application sends a request to the translation API.
4. The API processes the request and returns the translated text.
5. The translated sentence is displayed instantly on the interface.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **API Integration:** Translation API
- **Tools:** Browser-based application
